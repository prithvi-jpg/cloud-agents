# Code of conduct

We want technical disagreement to be direct, evidence-based, and respectful.

Contributors must not harass, demean, threaten, dox, or discriminate against others. Private data, credentials, and non-public user material must never be posted in issues, pull requests, examples, or discussions.

Maintainers may edit or remove content, lock conversations, or restrict participation when necessary to protect contributors and the project. Report conduct concerns privately to the primary maintainer through GitHub.
