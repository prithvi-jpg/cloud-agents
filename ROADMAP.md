# Roadmap

The roadmap is ordered by evidence value, not feature count.

## v0.1: portable operating contract

- Publish the skill, schemas, initialization utilities, and deterministic checks.
- Document the authority model and proof boundary.
- Collect reproducible feedback from at least three distinct project types.

## v0.2: compatibility fixtures

- Add fixtures for Codex and one additional agent harness.
- Publish schema migration checks and compatibility receipts.
- Add negative controls for approval, stale-state, and falsely green completion failures.

## v0.3: maintainer workflow

- Add issue-to-work-packet and pull-request verification examples.
- Evaluate whether the operating layer reduces rework or unsupported completion claims.
- Publish aggregate results and limitations without exposing private project data.

## v1 criteria

- Stable authority and state semantics.
- Documented schema compatibility policy.
- Evidence from repeated use across independent projects.
- At least one external maintainer or contributor validating the workflow.
